# Privacy

SysMon monitors hardware, processes and network activity locally on your Windows
computer. It has no telemetry or analytics service and does not automatically
upload monitoring data, logs, crash information or support reports.

Settings, optional monitoring/alert logs and diagnostic logs are stored locally.
Support reports are exported only when requested. They include the SysMon and
Windows versions, hardware models, sensor status and recent diagnostic errors.
Review any report, log or screenshot before sharing it: hardware details and
locally displayed process, device and network information may be sensitive.

When automatic update checking is enabled, or you manually check for updates,
SysMon sends an HTTPS request to GitHub's releases API. GitHub receives normal
connection information such as your IP address and SysMon's version in its user
agent. SysMon does not attach hardware inventories or monitoring reports to this
request. Opening a release page uses your browser and GitHub's privacy policy.
Updates are not forced.

Windows services, hardware drivers, and tools you launch from SysMon operate
under their own policies. SysMon does not control data those tools may send.

You control whether to share exported files. Delete local data using the data
folder shown in Settings when you no longer need it.
