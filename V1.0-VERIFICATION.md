# v1.0 release candidate verification

Verified on this Windows PC:

- Full native build and settings/unit tests passed.
- Background collection remained nonblocking; error recovery and shutdown passed.
- Reversible startup-entry test restored exact registry data and value type, rejected stale data, and removed its own test keys. No existing startup entry was changed by the test.
- An isolated blocked-cleanup test verified that the 15-second shutdown deadline terminates the process.
- Sensor lifecycle test passed pause, resume, normal stop and forced parent termination. No sensor child remained.
- Settings persistence, defaults, malformed values, overlay preferences, dark/light theme mapping and update-version comparisons passed.
- Windows validated the startup task XML without registering a task.
- Close-to-tray, normal close, restore and selected refresh timing passed.
- All pages rendered in dark and light themes at 100%, 125%, 150% and 200% drawing scales, plus wide layouts. Click/drag mapping passed across tested window dimensions.
- Package includes a self-contained x64 sensor helper and per-file SHA-256 checksums.

Still requires manual release acceptance:

- Actual Windows DPI changes across physical monitors, disconnected/reconnected monitors and repeated maximize/minimize/restore on additional PCs.
- Full accessibility: custom-drawn Settings does not yet expose every control to screen readers or Tab navigation. Keyboard shortcuts and native menus are available.
- Startup manager covers current-user Run entries. It does not measure startup impact or replace Windows management of scheduled tasks, startup folders and Windows-disabled entries.
- UI automation could capture the elevated preview, but injected navigation did not take effect, so the automated rendering tests do not substitute for a complete interactive acceptance test.
- Real failures across different WMI providers, sensors and network adapters cannot all be reproduced on one PC.
- No digital signature is present, as requested. This is an unsigned release candidate, not a claim that all final-release acceptance is complete.

The existing v0.9 archive is retained. Source changes are local and have not been committed or pushed.
